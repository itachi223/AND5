# And5 Studio — сайт студії українського дубляжу

Односторінковий сайт-візитка з п'ятьма «вкладками»: **Головна, Новини, Роботи, Команда, Контакти**.
Червоно-біла тема, великі дисплейні шрифти, анімовані переходи між розділами. Без збірки,
без залежностей — чистий HTML + CSS + JS.

## Як відкрити

Двічі клікнути `index.html` — усе працює просто з диска, сервер не потрібен.

Якщо хочеться відкрити «як справжній сайт» (і перевірити з телефона в тій самій мережі):

```bash
cd and5-studio
python -m http.server 8080
# далі: http://localhost:8080
```

## Файли

```
and5-studio/
├── index.html          # каркас: хедер, футер, порожній <main>
├── styles.css          # усі стилі: палітра, шрифти, анімації, адаптив
├── data.js             # ★ увесь контент: новини, роботи, команда, FAQ, контакти
├── app.js              # маршрутизація між вкладками, фільтри, форма, лічильники
└── assets/
    ├── logo.png        # логотип (хедер і футер)
    ├── favicon.png     # маленька іконка вкладки браузера
    ├── cover-orator.jpg, cover-kaiju-8.jpg   # обкладинки робіт
    └── process-*.jpg   # фото процесу роботи (блок «Про студію»)
```

Головний принцип: **текст живе тільки в `data.js`**. Щоб оновити сайт, код правити не потрібно.

## Як додати новину

Відкрити `data.js`, знайти `news: [` і додати об'єкт **першим** у списку (свіжіші — вище):

```js
{
  date: '2026-10-05',              // рік-місяць-день
  tag: "Прем'єра",                 // тег: автоматично стає фільтром на сторінці
  title: 'Назва новини',
  excerpt: 'Одне-два речення опису.',
  featured: true,                  // необовʼязково: виділить новину червоною карткою
  link: '#/works'                  // куди веде «Детальніше»
}
```

Новий тег не потрібно ніде реєструвати — кнопка фільтра з'явиться сама.

## Як додати роботу

У `data.js`, масив `works: [`. Категорія — довільний напрям (`Аніме`, `Серіали`, `Фільми`, `Ігри`,
`Аудіокниги`, `Реклама`, будь-що своє): кнопки фільтрів будуються з самих робіт, тож зайвих
кнопок без робіт не буде.

```js
{
  title: 'Назва проєкту',
  category: 'Аніме',               // Усі / Аніме / Серіали / Фільми / Ігри / Аудіокниги / Реклама
  year: 2026,
  role: 'Дубляж · 12 епізодів',    // що саме ви робили
  status: 'Вийшло',                // 'Вийшло' | 'У роботі' | 'Готується'
  progress: 65,                    // тільки для «У роботі»/«Готується» — смуга готовності
  letter: 'К',                     // велика літера на обкладинці
  accent: '#E4002B',               // колір обкладинки
  tags: ['9 акторів', 'мастеринг'],
  note: 'Короткий коментар про проєкт.'
}
```

Обкладинка і посилання на перегляд:

```js
cover: 'assets/cover-orator.jpg',   // картинка з папки assets — покажеться замість літери
link: 'https://...'                 // кнопка «Дивитися» на картці
```

Постери показуються у пропорції 3:4, майже без обрізання. Якщо `cover` не вказувати —
картка виглядає як раніше: кольоровий градієнт із великою літерою.

## Порожні розділи

Якщо якогось масиву немає або він порожній, блок просто не показується — сайт не ламається:

- немає `news` → зникає стрічка на головній, а на сторінці новин з'являється картка «Новин поки немає»;
- немає `works` → ховається секція портфоліо, на сторінці робіт — своя картка;
- немає `stats` / `services` / `ticker` → ховаються ці блоки, стрічка не біжить;
- незаповнені контакти (пошта, Telegram, Discord…) → рядок просто не виводиться.

Краще порожній масив, ніж вигаданий текст: сайт виглядає охайно в будь-якому стані.

## Команда, послуги, FAQ, контакти

- `team: [...]` — люди: `name`, `role`, `bio`, `tags`, `photo` (необовʼязково).
  Поки масив порожній — вкладка «Команда» автоматично ховається з меню й футера,
  а пряме посилання `#/team` веде на головну. Додасте людей — вкладка з'явиться сама.
- `about: { текст + gallery }` — блок «Про студію» на головній: `kicker`, `title`, `text`,
  `text2` і до трьох фото `gallery: [{ src, caption }]` (перше показується великим).
- `services: [...]` — картки послуг на головній.
- `faq: [...]` — питання-відповіді на сторінці контактів.
- `studio: {...}` — пошта, Telegram, Discord, YouTube, TikTok, SoundCloud, Donatello,
  графік, місто, рядки «Підготовка» і «Мови». Порожній рядок = рядок не показується.
  Telegram можна задати як `@нік`, так і повним посиланням — підпис і лінк зробляться самі.
- `ticker: [...]` — фрази для рухомого рядка на головній. Порожній масив = рядок
  збирається з заголовків останніх новин.
- `stats: [...]` — цифри на головній (анімовані лічильники).
- `steps: [...]` — етапи роботи над проєктом.

## Логотип

Лого лежить у двох файлах:

- `assets/logo.png` — знак 384×384 з прозорим фоном (хедер і футер);
- `assets/favicon.png` — версія 64×64 для іконки вкладки.

Щоб замінити — просто перезапишіть ці два файли своїми (png з прозорим фоном).
У футері лого стоїть на білій плитці, бо тло там темне.

## Кольори та шрифти

Усе в `:root` на початку `styles.css`:

```css
--red: #E4002B;        /* основний червоний */
--red-deep: #A80020;   /* темніший червоний (градієнти) */
--ink: #150A0E;        /* майже чорний текст */
--muted: #7B6A70;      /* другорядний текст */
```

Шрифти: **Unbounded** (заголовки) + **Manrope** (текст) — обидва підключені з Google Fonts
і підтримують кирилицю. Якщо сайт має працювати без інтернету, шрифти варто покласти
в `assets/fonts/` і замінити `<link>` в `index.html` на локальні `@font-face`.

## Переходи між вкладками

- Клік по пункту меню змінює хеш (`#/news`) — сторінка доступна за прямим посиланням,
  працюють «назад»/«вперед» у браузері.
- Під час переходу зверху проходить червоно-чорна «шторка» (`wipe` у `styles.css`,
  тайминги — у `navigate()` в `app.js`), потім контент з'являється каскадом.
- Блоки нижче першого екрана підсвічуються під час прокрутки (IntersectionObserver, клас `.io`).
- Якщо в системі увімкнено «зменшити рух» (`prefers-reduced-motion`), анімації вимикаються.

## Форма заявки

Зараз форма нічого нікуди не надсилає: вона перевіряє поля, показує повідомлення
й відкриває лист у поштовому клієнті (`mailto:`). Дані беруться з `studio.email`.

Щоб заявки приходили на пошту або в Telegram — треба бекенд, найпростіші варіанти:

- **Formspree / Getform**: замінити `<form>` на `action="https://formspree.io/f/XXXX"` і зняти
  `preventDefault` — решта лишається;
- **Telegram-бот**: у `app.js` замінити блок у `initForm()` на `fetch()` до вашого вебхука.

Скажіть, який варіант — підключу.
